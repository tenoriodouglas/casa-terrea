# casa-terrea

Preliminary design of a single-story house on a 12 × 41 m lot, viewable in any browser (desktop and mobile).

**Live site:** https://tenoriodouglas.github.io/casa-terrea/

## Features
- **Planta**: dimensioned 2D floor plan (drawn as seen from the street) with area table.
- **Maquete 3D**: orbit model with preset views and image capture.
- **Passeio**: first-person walkthrough (WASD + mouse on desktop, joystick + drag on mobile).
- **Tour 360°**: ray-traced equirectangular panoramas with hotspots between rooms.
- **Renders**: ray-traced still images.

Deep links: `#planta`, `#maquete`, `#passeio`, `#tour360`, `#renders`.

## Program
Living/dining, kitchen with island, powder room, 4 suites in pairs (master suite largest) with a short corridor, gourmet area with barbecue at the back, lawn and raised vegetable beds. Ceiling height 3.00 m, built area ≈ 205 m².
